v0.5.0 (1st release)
- First Release

v0.6.0 (2nd release)
- [Added] "Add Mod" and Open Mod Folder" to the context menu for the Mod List on the 'Mod Manager' menu as additional functions for convenience.
- [Added] feature for reading .txt files in a mod archive and viewing the contents of that .txt file.
- [Added] application version number on the application bar
- [Updated] Help URL

v0.6.5 (3rd release)
- [Removed] Creator Tab since it's no longer needed. The functionality and tools for creating mods will be moved seperately to the Telltale Script Editor and other related tools.
- [Removed] Game Mods Folder field during setup since it isn't necessary for the user to define, the launcher now automatically finds the correct folder for the game. (causes less confusion during setup, makes things easier for the user)
- [Removed] Lua Compiler dependency since it's not needed
- [Removed] Lua Decompiler depedency since it's not needed 
- [Removed] Removed the dependencies tab and it's options since it's not needed, and other depedencies are handled internally. No setup needed for the user.

v0.7.0 (W.I.P)
- [Changed] Rebuilt on .NET 10 and Avalonia, so the launcher runs on Windows and Linux.
- [Changed] New layout. Your games are listed on the left, the selected game sits at the top with a Play button, and its mods are listed below.
- [Changed] The setup wizard is replaced by "Add a game", and more than one game can be set up at once. Right-click a game to change its location or remove it.
- [Changed] The launcher opens on the last game you picked, which replaces the Default Game Version setting.
- [Changed] Mods are now sorted by priority
- [Changed] Can still add/replace a mod even if it has both the same name and version (will give you a prompt instead of not allowing you to do it)
- [Added] Support for most other Telltale Games (not all have been tested)
- [Added] Install a mod by dropping its .zip anywhere on the window.
- [Added] On Linux, Play starts a Steam copy of the game through Steam (Proton), or runs it with Wine when it isn't in a Steam library.
- [Added] Steam's library artwork is shown behind the selected game when Steam has it cached.
- [Added] Mod priority is read from the mod's resource description (_resdesc_*.lua) when that file is plain text, and shown next to each mod. Changing priorities is not in yet.
- [Added] The mod details window lists which files went to the mods folder and which to the game folder, and previews .txt, .ini, .json and plain .lua files.
- [Added] Mods with missing files are flagged in the list instead of being deleted on startup.
- [Added] Window Defocusing effect when opening other windows in the app (helps with useability, can be toggled off)
- [Added] Tooltips on the icon buttons and on the priority badge.
- [Added] Mod list refresh button. The list also refreshes when you switch back to the launcher.
- [Added] Mods (if supported) can now place files in the game directory automatically (useful since some mods will have .ini config files)
- [Removed] ttarchexe depedency, which has now been replaced by LibTelltale (By Lucas Saragosa).
- [Removed] The resource description editor that needed LibTelltale. Nothing called it and LibTelltale.dll was never in the repo, so the project could not build.
- [Removed] The exe icon preview, MahApps.Metro, Ookii.Dialogs, Newtonsoft.Json and IconExtractor.dll.
- [Fix] Fixed issue when the launcher would crash when opening mod files that were not properly structured. (i.e. if you downloaded the source code zip of a project rather than the actual mod zip). Now it warns the user and displays an error
- [Fix] Fixed issue when the launcher would crash on startup due to the file system watcher for mod refreshing
- [Fix] Files listed in ModFilesGameDirectory are copied next to the game exe. Before, the list was read into ModFiles by mistake and those files were never placed.
- [Fix] A mod's game compatibility is checked even when no other mods are installed.
- [Fix] Choosing to remove conflicting mods now goes on to install the new mod instead of stopping.
- [Fix] Two mods whose info files have the same name no longer overwrite each other.
- [Fix] Remove all only deletes mod info files, not every .json in the Archives folder.
- [Fix] Mod zips are read in place instead of extracting the info file next to the download.
- [Fix] A settings file that can't be read is backed up and replaced instead of leaving the launcher half loaded.
